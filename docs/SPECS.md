# 26/02

## Features principales

- Auth

### Événement

- Nom, date, addresse, description
- Un ou plusieurs tournois
- Staff: gestion de droits sur l'événement

### Tournoi

- Jeu
- Soit individuel soit par équipes
- Participants: import, inscription manuelle, inscription par le participant, participant a un compte ou non
- Equipes (jeux multi): comprend plusieurs membres

### Arbres de tournoi

- Simple élimination, autres si affinité
- Format (BO1, BO3...) avec score

### Organisations

- Membres
- Tournois
